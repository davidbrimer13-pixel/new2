
## BBC micro:bit Python music loop

`main.py` contains an original upbeat pop-style loop with a timed bass pulse and LED sound-level display. It is not a transcription of Coldplay's *Hymn for the Weekend*.

- Run the project on a **BBC micro:bit V2** (the built-in microphone is required).
- The LED bar graph reacts to the microphone's overall volume. The top-left LED marks the programmed bass beats; the microphone does not measure bass separately.
- The micro:bit speaker is monophonic, so it plays one note at a time.
